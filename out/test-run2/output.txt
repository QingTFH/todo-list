> 可用指令:
  stop  停止程序
  add -m 内容 [-d 日期] [-h 时间]  新增待办
  query [-f|-a|-n num]  查询待办, 加 -f 查询已完成
  finish num 或 finish -n num  完成待办, 移入finish.txt
  edit num 或 edit -n num [-c 内容] [-d 日期] [-h 时间]  修改待办内容或ddl
  delete num 或 delete -n num  彻底删除待办
  help [指令名]  显示指令帮助
